# Roadmap

## Beta Stabilization

- Test against multiple current Dify Community and Cloud versions.
- Add version capability detection and clearer endpoint compatibility errors.
- Expand IR support for branching, iteration, parameter extraction, and document extraction.
- Add deterministic repair fixtures for common canvas-render failures.

## Adoption

- Publish npm package and signed release archives.
- Add short demo recordings for Codex, Claude Code, and OpenClaw.
- Add more redistributable, target-version-tested workflow examples.
- Document Docker and fully offline installation paths.

## Later

- Optional approval policies for destructive tools.
- Pluggable API adapters if Dify publishes stable management APIs.
- Workflow diff, migration, and compatibility reports.

Roadmap items are directional, not commitments. Please open an issue before implementing a large item.
